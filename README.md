# CursorBar

Радиальное меню эмодзи для Windows. Вызывается глобальной горячей клавишей, открывается
прямо под курсором и вставляет выбранный смайлик в активное окно.

## Возможности

- **Радиальное меню под курсором.** Щёлкните по сектору — смайлик уйдёт в буфер обмена и
  вставится в активное окно. Клик мимо сектора просто закрывает меню.
- **Кольца появляются сами.** До 18 смайликов — одно кольцо, дальше добавляются второе и
  третье. Подписи автоматически уменьшаются, чтобы влезать в сектор.
- **Встроенный редактор** (`Ctrl+Shift+R`): добавление, изменение, удаление и
  перетаскивание смайликов, выбор вида колеса.
- **Три вида колеса:** классический, космический со звёздами и мили-фурри с лапками.
- **Своя картинка вместо фона.** Положите `background.png` рядом с программой.
- **Пользовательские данные рядом с программой.** Список смайликов хранится в
  `emojis.json`, вид колеса — в `settings.json`.

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| `Ctrl+Shift+E` | Открыть меню |
| `Ctrl+Shift+R` | Открыть редактор смайликов |
| `Esc` или правый клик | Закрыть меню |

Внутри редактора: двойной клик — изменить строку, `Delete` — удалить, `Ctrl+D` —
дублировать, `Ctrl+↑` / `Ctrl+↓` — поменять порядок.

## Установка

Нужен Python 3.10 или новее.

```powershell
pip install -r requirements.txt
python CursorBar.py
```

Готовую сборку можно сделать самостоятельно — см. раздел «Сборка .exe». Папку нужно
переносить целиком, `CursorBar.exe` без `_internal` не запустится.

## Сборка .exe

```powershell
pip install pyinstaller
pyinstaller --noconfirm --clean --windowed --name CursorBar `
  --icon CursorBar.ico --add-data "CursorBar.svg;." `
  --hidden-import keyboard --hidden-import pyperclip CursorBar.py
```

Результат появится в `dist/CursorBar/`. Это сборка папкой: ресурсы лежат в `_internal`,
рядом с `.exe` создаются ваши `emojis.json` и `settings.json`.

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `CursorBar.py` | Всё приложение целиком |
| `CursorBar.svg` | Иконка приложения |
| `CursorBar.ico` | Иконка для `.exe`, 7 размеров (16–256) |

## Как это работает

Меню — это прозрачное окно во весь экран, которое не забирает фокус, чтобы активное окно
можно было сразу получить обратно. Нажатия перехватывает библиотека `keyboard`, смайлик
попадает в буфер обмена через `pyperclip`, а вставку выполняет `Ctrl+V`, отправленный в
активное окно. Прежнее содержимое буфера возвращается через полсекунды, чтобы не затирать
то, что вы копировали до этого.

## Известные ограничения

- **Только Windows.** Используются глобальные хуки клавиатуры и отправка нажатий.
- **Нужны одинаковые права.** Если приложение запущено от администратора, а активное окно —
  нет (или наоборот), Windows не пропустит нажатия и `Ctrl+Shift+E` не сработает.
- Английская раскладка не требуется: горячие клавиши работают по позиции клавиш.
